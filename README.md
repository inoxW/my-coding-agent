# My Coding Agent

Мобільна панель AI-агента для VS Code та code-server. Агент читає й шукає файли, створює та редагує код, запускає команди й показує Git diff. Працює у відкритій локальній папці проєкту через OpenAI Responses API.

## Встановлення

1. Відкрий VS Code або code-server у браузері телефону.
2. Вибери **Extensions → ⋯ → Install from VSIX…** та вибери файл `my-coding-agent-0.1.0.vsix`. Якщо меню немає, у терміналі середовища запусти `code --install-extension my-coding-agent-0.1.0.vsix` або `code-server --install-extension my-coding-agent-0.1.0.vsix`.
3. Перезавантаж редактор і відкрий папку свого проєкту.
4. Відкрий іконку **Agent** → **API ключ**, введи власний ключ OpenAI API. Підписка ChatGPT не включає API-виклики.
5. Напиши завдання та натисни **Запустити агента**. Модель можна змінити в налаштуванні `myCodingAgent.model`.

Всі зміни файлів і команди потребують окремого підтвердження. Перевір код та Git diff після виконання. Ключ зберігається у VS Code SecretStorage. Агент надсилає запит та необхідні фрагменти проєкту до OpenAI API. Для захисту від випадкових запитів ліміт складає 20 кроків (налаштовується), файли обмежені 120 КБ, команди мають таймаут 120 секунд. Відкривай лише довірені проєкти: підтверджена shell-команда має звичайні права користувача.

## Збірка з вихідного коду

```sh
npm ci
npm run check
npm run package
```

Потрібні Node.js 20+ та npm. Папка `src/` містить вихідний TypeScript; `dist/` створюється під час збірки. Для GitHub завантаж вихідний код із архіву в новий репозиторій. MCP-підключення та локальні моделі у версії 0.1.0 поки не реалізовані.
